# 工小助 v0.5.6

- 精简课程新增与编辑弹窗的节次说明文字。未选择起点时不再显示静态操作说明；选择起点后仍显示下一步提示。
- 编辑课程时完整回显同一课程、同一星期及同一节次的全部原有周次，例如第 10–17 周、9–12 节会同时选中；仅提供一组上课周次，原课程全部安排继续只读展示。保存替换这组安排，保留其他星期和其他节次。
- 节次和周次支持长按未选项后拖动补选，普通滑动用于正文滚动，取消选择使用点击。新选节次限 1–12，旧的第 13 节及以后可整组原样保留；部分取消后仍含更晚节次时，提示重新选择 1–12 节并禁用保存。
- 保留单节与连续区间点选、反向选择、原非连续节次及周次快捷操作，避免误删目标周其他安排或生成学校课表重复目标。
- “我的”首页底部增加固定居中的 GitHub 图标与 `github` 入口，点击通过系统打开本项目首页；上方七个入口仍可独立滚动，适配深色、小屏和大字体。

版本 0.5.6／versionCode 37，沿用固定正式签名，可覆盖安装并保留校园网账号、课表、自定义课程、壁纸和设置。请勿先卸载或清除资料。小鸟图标、原开屏与加载动画保持原样。

2026 年 11 月 19 日按用户要求再次替换同一 v0.5.6 Release 的 APK、校验文件及更新信息，没有增加 versionCode。本次包含课程周次回显、拖动补选与滚动修复，以及 GitHub 入口。保留原 v0.5.6 标签，修订源码及附件核验记录见下方验证说明。已安装 v0.5.6 的用户需从本页下载并手动覆盖安装；App 内更新检查不会将相同 versionCode 识别为新版。
