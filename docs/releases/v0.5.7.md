# 工小助 v0.5.7

版本 0.5.7／versionCode 38，沿用固定正式签名。正式构建、覆盖安装及公开附件核验见 [v0.5.7 验证记录](https://github.com/TBeiMu/BJUT_gxz/blob/main/docs/testing/v0.5.7验证.md)。

## 11 月 20 日课表回滚与离线操作修订

- 今日课表浏览其他日期时，新增与“回到本周”同位置、同样式的“返回今日”按钮；点击重新读取当前日期并恢复自动跟随。
- “回到本周”沿上下方向连续经过中间周，“返回今日”沿左右方向连续经过中间日期；课程相同或没有课程时，也能看见清楚的返回过程。
- 回滚时长按跨度控制在 440–640ms，点击立即更新目标标题；固定星期、节次、时间栏和今日页顶部保持原位，按钮外观与位置不变。
- 回滚中可用新拖动接管当前画面；切页、后台、旋转及新选择取消旧动画，避免迟到结果覆盖操作。今日页保留纵向浏览位置和恢复行为，系统关闭动画时直接定位。
- 未连接 WiFi 时禁用“登录查询／刷新资费”，仍可查看当前账号最近一次成功结果；重新取得实体 WiFi 后恢复可用，原自动刷新机制保持。

## 11 月 20 日资费修订

- 资费只保存最近一次成功查询结果，重启后仅为当前账号恢复；全局只留一条加密缓存，最多 32KiB，不积累历史。
- 普通刷新失败时右上角显示“查询失败”，保留原资费、设备信息和成功时间；验证码、登录未确认及注销结果继续保留必要提示。
- 查询结束后明确反馈结果：没有其他必要提示时显示“查询成功”，普通失败显示“查询失败”，不再从“正在查询”直接变为空白；刷新未确认、验证码、登录确认及注销结果等具体提示仍保留。
- 修复断开或切换 WiFi 时立即清空资费的问题。同一账号的最近数据及原查询时间继续保留，重启后也可恢复；网络变化只取消旧查询和会话，旧设备信息须刷新成功后才可注销。
- 自动刷新机制保持：每次进入前台后，首次打开资费且账号和 WiFi 就绪时自动尝试一次；同次前台重复切页不重复查询，仍可手动刷新。
- 恢复的设备信息只供查看，刷新成功取得当前信息后才允许注销；不保存密码、Cookie、验证码或真实注销标识。
- 刷新已有结果时不切换成占位动画，保持卡片、按钮和右上角提示的位置稳定。

**本次按用户要求仍为 0.5.7／38，替换同一 Release 的附件。已经安装 0.5.7 的用户需要下载新版 APK 手动覆盖安装，应用内不会提示同版本更新；无需卸载或清除资料。原 v0.5.7 标签保留，修订构建使用验证记录中的明确源码提交。**

## 校园网集中在一页

- “我的”将原“校园网账号”“校园网连接”合并为“校园网”，首页共六个入口，底部 GitHub 入口保持。
- 页面上方是当前账号、连接状态和登录操作，下方是账号管理；底部“连接设置”默认折叠，展开后可修改自动登录及网络模式。
- 资费“管理账号”直接定位账号区域，顶部或系统返回都回到资费；认证通知定位顶部连接区，返回“我的”。
- 旋转保留滚动位置、设置展开状态和返回来源。修复窗口初始尺寸变化导致恢复位置偏移的问题；用户滚动、展开认证耗时、操作通知权限或收到新入口请求时，旧恢复不再把页面拉回。

## 姓名补全

- 优先使用本机相同学号的已验证课表姓名。需要联网时，须在前台确认当前实体 WiFi 的校园认证成功；仅能上网、认证失败或超时均不会提前消费机会。
- 每次 versionCode 递增，为仍未取得姓名且没有自定义备注的账号重新提供一次机会。已有姓名、自定义备注、默认账号和课表绑定保持。
- 开始前先加密保存本版本已尝试标记；失败、验证码要求、30 秒超时及同版本重启或覆盖安装均不自动重试。升级后仍须先满足校园认证成功条件。
- 等待写入时认证失效不会发出查名请求；返回前台重新确认同一 WiFi 后不会漏掉首次机会。

## 维护修复

- 调课同时修改课程名、教室或教师时，保留修改后的目标安排和未选中的原安排，避免误当作重复目标丢弃。
- 第 13 节以后没有提供作息时间时，不再误报当天课程已全部结束。
- 设备注销请求的响应丢失或异常时，明确显示“注销未确认，请刷新核对”，不声称成功或自动重发。
- 修复校园 WiFi、课表与更新监听初始快照期间漏失断网或换网的问题。
- 修复认证结束后迟到的重复启动／取消命令留下空闲服务、阻挡后续认证的问题；请求清理期间继续保留原任务槽。
- 旧下载通知的取消操作只作用于其所属任务，避免取消新下载或停止较新的服务启动。
- 系统动画设置在返回 App 后及时生效，关闭动画时停用装饰性动效。小鸟图标及原开屏、加载图形设计保留。

## 更新与验证

沿用固定正式签名，versionCode 38 高于 v0.5.6 的 37。v0.4.9 至 v0.5.6 可在 App 内检查更新；已安装 v0.5.7 的用户须手动覆盖同版本修订。覆盖安装无需先卸载或清除账号、课表、自定义课程、壁纸和设置。v0.4.8 及以前因仓库旧地址迁移仍需手动覆盖安装一次。

本轮返回按钮及回滚修订完成 Debug 571 项、Release 512 项单元测试、两种 Lint、Debug 与设备测试 APK 构建，以及 Android 12／16 各 45 项相关设备检查，全部通过；正式签名构建与公开附件核验按发布工作流及验证记录确认。本版同时汇总此前合并页、姓名补全和资费维护，不替换历史 v0.5.6 附件。检查使用虚构账号、课程和服务器响应；真实校园认证、CAS 查名、资费注销、学校课表导入及不同手机品牌行为仍按现场验证记录确认。专项历程见[返回按钮与回滚](https://github.com/TBeiMu/BJUT_gxz/blob/main/docs/testing/返回今日按钮验证.md)、[断网保留](https://github.com/TBeiMu/BJUT_gxz/blob/main/docs/testing/资费断网保留修复验证.md)、[资费缓存](https://github.com/TBeiMu/BJUT_gxz/blob/main/docs/testing/资费最近结果缓存验证.md)、[维护体检](https://github.com/TBeiMu/BJUT_gxz/blob/main/docs/testing/维护体检与修复验证.md)、[姓名补全](https://github.com/TBeiMu/BJUT_gxz/blob/main/docs/testing/账号姓名补全验证.md)和[校园网页面合并](https://github.com/TBeiMu/BJUT_gxz/blob/main/docs/testing/校园网页面合并验证.md)。
