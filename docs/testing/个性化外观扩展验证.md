## 本轮范围

本轮只在源码中增加个性化外观选项，未修改版本号、签名、发布附件或正式 Release。新增内容位于“我的 → 个性化”：

- 界面主题：跟随系统、浅色、深色。手动模式同时作用于背景、卡片、文字和系统栏图标。
- 强调色：朱红、晴空蓝、松绿、暮紫。只替换现有“今日／此刻／选中”等强调标记；品牌朱红、主操作控件、错误／成功语义色和课程配色保持原规则。
- 卡片通透度：2%–16% 透明度，提供轻透、默认、清晰三个快捷档位。只调整通用半透明卡片背景，数值越大，透出的背景越明显；文字与图标不随其变淡。
- 推荐搭配：纸感经典、清爽晴空、深夜松绿，一键应用主题、强调色和卡片通透度，保留当前壁纸、图片和模糊值。
- 恢复默认外观：恢复蓝青背景、系统主题、朱红和 96% 卡片不透明度，保留已选图片和模糊值。

配置继续写入现有 noBackupFilesDir/wallpaper.json，使用原子替换；新增字段均有默认值，旧版 v1 配置无需迁移即可读取。没有增加文件、网络请求、权限或依赖。
