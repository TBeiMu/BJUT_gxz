# 考试管理列表优化验证

日期：2026 年 11 月 27 日（上海时间）。本项同步维护 Android／iOS 源码，版本保持 0.5.9／40，不发布 Release、不替换公开双端安装包。

## 展示与时间规则

- 移除考试分类筛选；iOS 同时移除来源筛选及状态分组标题，保留搜索。正常列表仅显示可见记录，已隐藏考试仍可查看、恢复。成绩分类及学期筛选不变。
- 未结束记录按开始时间升序，开始时间未知的记录排在这一部分末尾；已结束记录统一置后，按结束时间倒序。同时间以名称、记录 ID 稳定排序。
- 仅使用个人修改后的本机字段；开始、结束均可解析，结束不早于开始，且当前上海时刻晚于结束时才标记结束。恰好等于结束时仍未结束，之后的时钟更新转为已结束。缺失、无法解析或倒置时间保留原文及原有占位，不猜测结束状态。
- 已结束卡片的名称、日期、地点及标记均使用主题灰色，保持点击与操作可用；时间段改为“已结束”，保留日期，窄屏／大字体布局仍保留日期。详情完整起止时间不改。
- 单一时间快照用于排序、颜色及文案。前台分钟／日期／系统时间变化及返回前台重新计算，离开页面或后台释放监听或取消任务；不新增联网、通知或持久化字段。
