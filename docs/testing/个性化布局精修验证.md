## 本轮范围

沿用此前本地个性化扩展，对“我的 → 个性化”重新排版。仍仅保留本地源码，不推送、不修改版本号或签名、不发布 Release；当前公开 v0.5.7／38 APK 不包含这些改动。

- 页面由单张长卡片改为效果预览、推荐搭配、背景、主题与配色、卡片通透度五个分组；保留现有顶部返回、底栏和统一纵向滚动。
- 效果预览复用实际背景、图片、模糊与主题配色，展示课程色块、强调标记、半透明卡片和胶囊底栏的视觉样例，不显示虚构身份或学校数据。竖屏保持样例比例并限制高度，横屏／宽屏改为摘要与预览并排，避免按屏幕宽度拉成过高的大图；大字体不会放大样例中的几何图形。
- 推荐搭配改为带缩略图的选择卡，选中以细描边和勾选共同确认；按每项可用宽度及当前字号选择三列或横向图文列表，宽屏的大字体仍可并排比较。
- 背景选择使用简短分段标签和六张渐变色卡；桌面壁纸取色保留实际状态反馈，自选图片使用细轨道、圆形手柄与原照片选择器。
- 主题选择使用同一组手机、太阳和月亮线条图标；分段控件、背景色卡、强调色色环与通透度快捷项均按可用宽度和当前字体选择列数，不简单地把所有大字体强制排成单列。强调色保留名称与选中勾，不依靠颜色单独表达选中。
- 通透度使用固定基线的百分比、细轨道、圆形手柄和清晰／默认／轻透三个快捷档位，保留 2%–16% 范围、实时预览与松手保存。数值说明保留，正文文案缩短以改善窄屏换行。
- 预览标题的处理标识与主题图标共用固定 20dp 区域；底部保留默认恢复及必要失败反馈。背景与新增选择动效遵循系统关闭动画设置。
- 收尾审查补齐图片模糊与卡片通透度滑杆的读屏名称、当前值；深色背景色卡略加深并使用白色名称，改善小字号对比度。

布局沿用纸白、墨色、现有半透明卡片、细边线和轻投影。蓝色小鸟、原开屏与加载动画、操作控件配色、课程色与语义色保持原规则。未增加依赖、网络请求、权限、设置项或配置文件。

## 实现与兼容

主要界面位于 WallpaperSettings.kt，几何预览独立位于 AppearancePreview.kt。Theme.kt 抽出纯配色函数供真实页面与缩略图共用；预览不嵌套窗口主题，不改系统栏、不写设置。Wallpaper.kt 在系统关闭动画时直接应用目标颜色。Debug 展示场景同步读取外观偏好，以便核对真实页面布局。

所有选择仍调用原 WallpaperState 回调，复用原 wallpaper.json、原子保存、图片引用及失败回退。推荐搭配仍保留当前壁纸、图片和模糊值，恢复默认仍保留图片及模糊值。导航、账号、课表、认证、资费及更新逻辑未扩展。
