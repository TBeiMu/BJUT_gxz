# 课表切换按钮通透度验证

日期：2026 年 11 月 27 日（上海时间）

## 范围与行为

按用户要求，安卓与 iOS 同步调整课表右下角的“今日／整周”视图切换按钮，使按钮背景跟随现有卡片通透度设置。文字、图标维持不透明，细边框保持；100% 通透度时移除底色。保留原按钮文案、图标、位置、切换与选择恢复行为，不调整“返回今日／回到本周”磨砂定位按钮。

安卓切换按钮从独立强实色表面改用现有普通卡片绘制，直接跟随主题中的卡片 alpha，不增加独立设置、存储或动画；同时沿用普通卡片不使用系统 elevation 的规则，避免全透明后仍有阴影底块。iOS 读取同一份卡片通透度，使用与卡片相同的深浅主题底色及独立细边框，仅对底色设置 opacity，不对整个控件设置 opacity。

沿用双端 0.5.9／40，不打标签、不发布 Release，不替换公开安装产物或更新元数据。

## 安卓检查

在从主分支创建的隔离工作目录执行，仅包含本次源码和测试，保留原工作区的其他未提交修改。

```powershell
./gradlew.bat :app:testDebugUnitTest --tests 'io.github.tbeimu.gongxiaozhu.ui.ScheduleModeOpacityTest' --tests 'io.github.tbeimu.gongxiaozhu.ui.ScheduleReturnAnchorTest' :app:lintDebug :app:assembleDebug --no-daemon --max-workers=2 '-Pkotlin.compiler.execution.strategy=in-process' --console=plain
```

- 新增 `ScheduleModeOpacityTest` 2 项通过：浅／深两种主题分别检查 0%、4%、20%、34%、50%、100% 通透度及返回默认 4%，每档覆盖“今日／整周”两种文案，共 28 组静止背景像素对照；确认背景与普通卡片相同、文字 alpha 为 1、按钮锚点不变，且点击仍能切换。像素对照独立于原有按压水波纹，保留既有点击反馈。
- 现有 `ScheduleReturnAnchorTest` 4 项通过，覆盖正常／大字体、长学期和暂停导入时的课表按钮锚点。6 项测试均无失败、错误或跳过。
- Debug Lint 和 Debug APK 构建通过；没有增加依赖或更改正式签名配置。
- 浅／深主题及全不透明、中间档和全透明的绘制截图用于视觉复核。记录保留在被忽略的 `local/schedule-mode-opacity-check.log` 与 `local/schedule-mode-opacity-preview/`，不提交截图、测试报告或安装包。

## iOS 与验证边界

iOS **按用户要求未验证**，本轮不执行 iOS 编译、静态检查、模拟器、真机或安装验证，不配置或使用 Apple 签名材料。

安卓使用虚构课表及独立纯色背景，JVM 图形渲染检查不等同于实体手机或真实校园网络验收；不新增或更改学校请求、账号、课表与外观资料格式。构建使用单次 Gradle 进程和进程内 Kotlin 编译器，完成后自动退出；本轮不启动模拟器或后台服务，也不停止其他任务的进程、模拟器及会话。
