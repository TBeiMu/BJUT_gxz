# 个性化提示精简与零通透度验证

日期：2026 年 11 月 27 日。范围：Android 个性化页面源码维护，沿用 v0.5.9／versionCode 40。

## 改动

- 删除“推荐搭配”标题下的“一键应用，保留当前壁纸”。
- 删除强调色选项下的“只改变强调标记，课程颜色保持原样。”。
- 删除卡片通透度滑杆上方的“数值越大，卡片越透明；100% 时卡片底色完全透明。”。
- 卡片通透度改为 0%–100%，仍每档 2%，共 51 档。0% 对应卡片底色 alpha 为 1，100% 对应 alpha 为 0；保留细边框及文字、图标的原有绘制规则。
- 同步放宽配置中的卡片不透明度校验上限至 100%，实时预览、保存及重新加载均使用原配置格式。默认 4% 及“默认 4%／轻透 20%／全透 100%”快捷档位不变。

## 本地检查

使用项目自带 `gradlew.bat` 执行：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:testReleaseUnitTest :app:lintDebug :app:lintRelease :app:assembleDebug :app:assembleDebugAndroidTest --console=plain
```

结果通过：Debug 702 项、Release 610 项单元测试，失败、错误及跳过均为 0；两种 Lint、Debug APK 与设备测试 APK 构建成功。`git diff --check` 通过。

原有配置测试增加完全不透明的配色与照片遮罩检查、99%／100% 不透明度序列化往返，并继续拒绝 -1%／101% 越界配置；旧配置及恢复默认检查通过。

## 设备界面检查

在隔离的 Android 12／API 31 和 Android 16／API 36 模拟器运行原 `WallpaperTest` 全组，两套系统均 **15／15 通过**，分别用时 49.805 秒与 58.287 秒。

检查覆盖三处提示移除，真实触摸 0%／100% 端点、实时预览 alpha、百分比与读屏描述、0% 和 100% 设置保存及 Activity 重建恢复、快捷档位与 50% 中间值、两倍字体、横屏、旧设置、图片及保存失败回退。逐档像素检查扩至深浅主题各 51 档，每个组合在卡片内容区及内边距选取 25 个点，与单层填充参考对照。

每台模拟器共 102 个主题／档位组合、2550 个采样点通过。已人工查看两系统 0% 界面，以及推荐搭配、主题配色的两倍字体和横屏通透度截图，未见本次改动导致的文字重叠或控件截断；长页面继续按原规则滚动。
