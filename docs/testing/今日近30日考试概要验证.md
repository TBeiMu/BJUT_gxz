# 今日近30日考试概要验证

日期：2026 年 11 月 27 日（上海时间）。Android／iOS 后续源码维护，版本保持 0.5.9／40，本轮不发布或替换公开附件。

## 展示与规则

- 今日滚动内容末尾以无底色紧凑列表最多展示最近 3 场，按开始时间、名称和记录 ID 稳定排序。每场只显示名称、开始日期时间与“剩N天”，当天显示“加油！”。不显示标题、总场数、地点或结束时间；点按任意一场进入原考试管理。
- 窗口跟随课表实际浏览日期，包含当天起连续 30 个自然日；整周不显示。未导入课表时以今天计算，仍可查看独立保存的考试。
- 剩余天数按上海实际当前日期到考试开始日期的自然日差计算，不随课表浏览日期改变，不按剩余小时数取整；跨日、分钟事件、返回前台及资料变化后重新计算。有效未结束考试的日期差小于或等于 0 时显示“加油！”。
- 排除已隐藏和现实时间中已经结束的记录，即使浏览过去日期也不展示历史已结束考试；使用本机修改后的字段，不按同名合并不同记录。开始时间未知时不猜日期；结束时间未知或倒置时，仅保留开始尚未过去的记录。有效结束时刻等于当前时刻时保留，下一次时钟更新后排除。
- 无匹配考试、读取中或教务存储异常时整块隐藏；不新增登录、查询、通知或后台任务，不改变已有课表标题、翻页、底栏和视图切换锚点。
