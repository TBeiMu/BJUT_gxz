# 资费最近结果缓存验证

日期：2026 年 11 月 20 日。基线为已发布 v0.5.7／versionCode 38 的源码 `102ff849ce5f0df441ee9704f775d5d302be5115`。本轮根据用户确认的方案维护源码，版本不变，不创建标签、发布 Release 或替换线上 APK／更新元数据。

## 行为与存储范围

- 仅保存最近一次成功查询结果，全局一个文件，以当前本机账号 ID 匹配恢复，不积累历史或为多个账号分别保留缓存。内容为四项已知资费指标、设备显示字段及成功查询时间。普通失败保留这些内容，右上角显示“查询失败”，不把旧时间改为失败时间；验证码、登录未确认、账号不符、会话失效及注销结果仍保留必要提示。
- 既有自动查询、手动刷新、验证码和内置网页登录流程保持；恢复不消耗自动查询次数，也不创建学校登录会话。冷启动首份 WiFi 快照只建立当前网络身份；后续确认断网或换网仍清除旧显示并失效缓存。临时账号加载与暂停网络监听不误当账号删除或断网。
- 切换／编辑账号、账号存储失效、账号不符及查询会话过期时清除旧显示并失效缓存；用户确认注销设备后，发送注销请求前等待缓存清理任务及校园认证请求清理。缓存故障不阻断有效账号或明确的注销操作；清理失败可能留下磁盘旧快照，但它重新恢复后始终只读，不能用于注销。
- 缓存在 `noBackupFilesDir/billing-cache.vault` 中通过 AtomicFile 原子覆盖，独立 Android Keystore 别名 `gongxiaozhu.billing.cache.v1`，AES-GCM 每次使用新随机 IV。密文文件最多 32KiB，最多 64 台设备，字段及 UTF-8 总字节有界。原子替换期间可有短暂恢复文件，正常只留一个快照文件。
- 不保存密码、Cookie、验证码、网页／HTML、诊断、服务器原始提示或真实注销 sessionId。恢复设备使用合成显示 ID，设备读取错误仅保留固定类别。缓存读写、损坏或缺钥不阻断账号及查询；失败／超限写入保留旧缓存，不删除账号文件或密钥。
- 恢复数据和查询失败后保留的数据均关闭设备操作；只有当前完整成功查询取得有效设备信息后开放注销。控制器的请求与最终确认各自复核，界面的总入口、单设备按钮和设备选择器同步禁用。

## 自动化检查范围

所有资料、凭据、IP 和设备均为虚构。JVM 检查覆盖单条覆盖、账号匹配、随机 IV、容量、损坏／缺钥／写入失败、取消后迟到读写、首网络快照、账号加载及失效、普通与网页登录错误、自动查询次数及注销前清理。

设备检查使用隔离的 Android 12（API 31）与 Android 16（API 36）模拟器。真实 Keystore／AtomicFile 检查使用专属测试目录与虚构资料，并核对原账号文件摘要不变；缺钥模拟仅删除随机测试别名。端到端检查将真实缓存工厂接入控制器，成功保存后重建控制器与仓库，验证冷恢复、自动刷新失败保留原值和时间、同次前台不重复自动查询。

界面检查包含浅／深色、360dp 小屏、正常及 1.8 倍字体，验证刷新前后和失败时卡片／按钮位置稳定、旧数值／设备／时间可见、提示与加载动画间距，以及缓存只读和选择器失效关闭。既有资费布局、验证码、前后台／换网、内置网页回归同时执行。
