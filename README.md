# 工小助

工小助是面向北京工业大学学生的校园应用，支持 Android 和 iOS。你可以用它看课表、查考试和成绩、登录校园网，也可以在出门前看看下一班校车几点发。

## 课表

- **今日课程**　按上课顺序查看当天安排，点开课程就能看到节次、教室和任课教师。切换到「整周」后，Android 上下滑动换周，iOS 左右滑动换周。
- **整学期导入**　登录后可一次导入整个学期的研究生课表，保存在手机上，离线也能查看。
- **自定义课程**　可以从空白学期开始排课，也可以在已有课表上添加课程。遇到调课时，可按周次、星期和节次调整本机安排。

## 考试与成绩

- **考试安排**　从研究生教务系统导入考试时间和地点，也可以手动添加考试、修改安排或隐藏学校考试。「今日」课表最多列出从所选日期起 30 天内最近的三场未结束考试。
- **成绩与学分**　按学期筛选成绩，分别查看学位课程和选修课程的成绩与学分，也能查看学校给出的已修学分和应修学分。查询成功后可离线翻阅。

## 校园网与资费

- **校园网登录**　支持学校公共 Wi-Fi 和宿舍 Wi-Fi。多个账号可在本机加密保存，选好默认账号并开启自动登录后，连上校园 Wi-Fi 再打开 App 即可发起认证。
- **流量与余额**　查看已用流量、可用流量、账户余额和消费保护。断开 Wi-Fi 后，仍可查看最近一次成功查询的结果。
- **在线设备**　查看各台设备的登录时间、在线时长和使用流量。需要让某台设备下线时，选中该设备并确认即可。

## 校车时刻表

离线查看中蓝校区与校本部之间的早晚班次、沿途站点和末班车时间。周一至周五默认显示工作日班次，周六、周日显示休息日班次，也可以手动切换。当天的时刻表会标出下一班计划发车时间。

## 个性化与更新

外观可跟随系统，也可固定为浅色或深色。你可以更换强调色、选择渐变背景，或用自己的照片作背景，并分别调整图片模糊程度和卡片通透度。在「我的」中可以直接检查应用更新。
