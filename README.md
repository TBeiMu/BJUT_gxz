# 工小助

北京工业大学校园助手。整学期课表、考试与成绩管理、校园网登录和资费查询集中在一个 App 中。

**v0.5.9 正式版 · Android 12 及以上 · versionCode 40**

用户已确认 v0.4.8 的主要功能基本齐全并可用。项目进入维护与体验优化，源码仓库为 [TBeiMu/BJUT_gxz](https://github.com/TBeiMu/BJUT_gxz)。

v0.5.9 延续考试／成绩管理及个性化设置，卡片通透度现为 2%–100%；全透明时移除卡片底色和阴影并保留原细边框，考试／成绩首页入口更紧凑。详见[本版更新说明](docs/releases/v0.5.9.md)与[验证记录](docs/testing/v0.5.9验证.md)。

本版沿用固定签名、蓝色小鸟图标及原开屏与加载动画，保留校园网页面合并、每版本姓名补全机会、课程编辑防误退、撤销、删除范围预览和 GitHub 入口。历史修订见 [v0.5.6 更新说明](docs/releases/v0.5.6.md)与 [v0.5.7 更新说明](docs/releases/v0.5.7.md)。

课表返回修订已于 2026 年 11 月 20 日 22:06:27（上海时间）完成 v0.5.7 三个附件替换及公开核验，包含“返回今日”、两个返回按钮的连续回滚与统一定位，以及未连接 WiFi 时禁用资费查询；此前查询结果提示、断网保留和单条资费缓存继续保留。仍使用 0.5.7／versionCode 38、原标签及固定签名，两种系统的正式包覆盖检查均通过，详情见[验证记录](docs/testing/v0.5.7验证.md)。

## 三页功能

| 页面 | 功能 |
| --- | --- |
| 课表 | 一次学校登录导入研究生整个学期，离线查看；默认“今日”时间线，可切换整周网格、上下切周、查看课程详情与重叠课程；离线添加自定义课程，编辑和删除本次或指定周次 |
| 资费 | 已用流量、可用流量、消费保护、账户余额、在线设备及单台设备注销 |
| 我的 | 考试管理、成绩管理、校车时刻表、课表管理、校园网、个性化、检查更新、关于工小助 |

上述功能表按 v0.5.9 展示；历史 v0.5.6 仍保留“校园网账号”“校园网连接”两个入口。校园网合并页上方显示连接状态与登录操作，下方为账号管理，底部“连接设置”默认折叠，展开后可修改自动登录及网络模式。资费的“管理账号”直接定位账号区域，返回后回到资费；认证通知回到顶部连接区。旋转保留浏览位置与设置展开状态，用户滚动、展开认证耗时或操作通知权限后，旧恢复任务不会把页面拉回。验证见[校园网页面合并验证](docs/testing/校园网页面合并验证.md)。

“我的”顶部优先显示默认账号备注，未填备注时显示完整学号／账号；副标题显示按时段变化的暖心文案，三句按天轮换，去掉原学号的胶囊底色。已合入 v0.5.3，见 [个人页验证](docs/testing/个人页时段文案验证.md)。

“我的”首页底部增加 GitHub 图标与 `github` 入口，固定在底部导航栏上方居中，点击通过系统打开本项目首页，上方内容仍可滚动。已随 2026 年 11 月 19 日 v0.5.6 修订版发布，验证见 [GitHub 入口验证](docs/testing/个人页GitHub入口验证.md)。

2026 年 11 月 20 日发布的 v0.5.6 修订版将“外观设置”入口及页面标题更名为“个性化”，并加入以下操作优化。

- 课程和账号编辑有修改时，点击弹窗外部保留草稿，取消或返回先确认。旋转后可继续编辑，改回原值可直接退出。在课程编辑弹窗侧边滑动会保留编辑器。
- 已有课程编辑或删除后，可通过底部“撤销”短时恢复。若有更新弹窗遮挡，等弹窗关闭后才显示并计时。新增或内容未变化时不显示撤销，切到后台或开始下一次课表操作后失效。
- 编辑已有账号时，没有实际修改便不能重复保存。
- 资费验证码可通过键盘“完成”提交，仍由用户主动操作。
- 只有一台在线设备时，点击注销直接进入最终确认；多台设备仍需先选择。
- 删除课程时显示实际周次、星期、节次及安排次数，默认只选本次，按钮明确为“删除这 N 次安排”。

上述六项已完成单元测试、Lint、构建及 Android 12／16 模拟器回归。v0.5.6 当时的同版本修订需手动覆盖安装；v0.5.7 使用更高版本号，可通过 App 内更新。详见[操作体验验证](docs/testing/操作体验六项优化验证.md)。

课表是默认首页，默认显示“今日”：今天的课按时间排成时间线，正在上的课显示进度与剩余时间，课间显示空闲时长，末尾预告明天的课；上方七天条可点选或左右滑动切换日期。浏览其他日期时，右侧提供磨砂“返回今日”按钮，点击后沿左右方向连续滚回当天，并按当前日期恢复跟随。右下角“整周”切换到整周网格，选择会被记住。

v0.5.1 固定了“今日／整周”切换按钮的位置，以及左上角小字和标题区的占位；校园网提示与周次切换时不再推动周围布局，并修复“我的 → 检查更新”结束后箭头漂移。详见 [课表布局验证](docs/testing/课表布局稳定性验证.md)与[更新箭头验证](docs/testing/检查更新箭头稳定性验证.md)。

整周网格每页展示 12 节及北工大上课时间，并以“此刻线”标出当前时间，向上划下一周、向下划上一周；课程跟随手指移动，日期同步过渡，星期和左侧时间栏固定；慢拖超过课程区域的 25% 或快速划动翻一周，短拖回弹，首末周不循环。保留 v0.4.12 的连续轻划与松手后周次即时反馈。右侧圆点可展开周次列表，“回到本周”位于圆点下方，从右侧滑入，使用模糊半透明底色；点击后沿上下方向连续滚回本周。支持自定义壁纸、深色模式和字体放大。

两个返回操作在点击时立即确定目标并更新标题，课程区域快速经过中间周／日，动画按跨度控制在 440–640ms；系统关闭动画时直接定位。中间页面仅用于展示，不改变选择或重复触发反馈。本轮 v0.5.7 同版本修订纳入返回按钮及动效，验证见[返回按钮与回滚验证](docs/testing/返回今日按钮验证.md)。

## 开始使用

### 查看校车时刻

“我的 → 校车时刻表”位于课表管理上方，离线展示中蓝校区—北工大专线：左列为中蓝公寓早间 12 班，右列为月亮湖西站晚间 9 班，下方列出完整路线，末车分别为 10:00 和 22:00。按上海时间高亮全表下一班计划发车，发车当分钟仍保留，下一分钟切换；当日班次结束后显示结束提示，跨日重新计算。

时刻来自用户提供的班次，未限定工作日或有效期；“下一班”表示计划发车。无需校园网账号、课表绑定或网络连接。该功能随 v0.5.5 发布，验证结果见 [校车时刻表验证](docs/testing/校车时刻表验证.md)。

### 导入课表

1. 连接可上网的 WiFi 或开启移动数据，点击课表右上角“＋”，选择“导入研究生课表”。
2. 在学校统一身份认证页面输入学号、密码及需要的验证码，完成一次登录。
3. App 自动获取当前整个学期，无需逐周操作。提交学校登录后，切换 App 或锁屏仍可继续导入，完成后可离线查看。

课表绑定独立学号，不跟随校园网默认账号切换。统一认证密码不会保存。后台导入显示静默进度通知，可点按返回课表或暂停；完成后通知自动移除。网络断开或切换、手动暂停、从最近任务划掉 App 或系统停止任务后保留进度，返回后手动继续并重新登录，也可取消本次导入。刷新全部完成前保留旧课表。

v0.5.1 支持后台继续导入，v0.5.0 及以前仍需保持前台。详见 [后台导入验证记录](docs/testing/课表后台导入验证.md)。尚未提交的学校登录表单在切后台后仍会关闭，需要返回 App 登录；单次导入最长运行 30 分钟，不自动重试。

课表右上角“＋”先选择研究生课表导入或添加自定义课程，本科生导入暂未开放。自定义课程可离线按星期、周次和节次安排，首次先设置本地学期；学校及自定义课程均可在详情中编辑、删除本次或指定周次。编辑只显示一组周次选择，原有周次、星期和节次会一并展示；新选节次为第 1–12 节，学校导入的更晚节次仍可原样保留在原周次和星期。完整刷新后学校课程以新数据为准，自定义课程保留；旧本地学期可在“我的 → 课表管理”查看。详见 [课程添加与编辑验证](docs/testing/课程添加与编辑验证.md)。

自定义课程的星期支持多选，多日调课超过单条容量时分开保存并保留其他安排；详情简化为课程卡片，编辑、删除和右侧关闭同排。已合入 v0.5.3，见 [本次验证](docs/testing/星期多选与详情布局验证.md)。

2026 年 11 月 27 日源码维护同步扩展学校课程编辑的星期多选，添加及编辑课程的星期标题不再附带选择方式说明。所选星期与周次组合保存，保留其他原安排并去重；原有晚节次限制不变。验证见 [课程编辑星期多选验证](docs/testing/课程编辑星期多选验证.md)。

2026 年 11 月 19 日起，课程新增和编辑弹窗全部选项直接展开，取消及保存固定；节次点选起止范围，可选单节，周次提供全部、单周、双周和清空。原课程全部周次、星期和节次只读展示；新选节次限 1–12，原有更晚节次仅可留在原周次和星期。v0.5.6 修订版修复单次编辑误删目标周原安排，并避免学校课表目标时段重复；节次区仅在选中起点后显示下一步提示。当时沿用 versionCode 37，需手动安装同版本修订；v0.5.7 继续保留这些功能并提供正常版本升级。详见 [课程编辑体验优化验证](docs/testing/课程编辑体验优化验证.md)。

同日后续修订版改为在编辑时默认选中同一课程、同一星期及同一节次的全部原有周次，例如第 10–17 周、9–12 节会同时回显。修改周次和节次后，保存替换这组原安排，保留其他星期及其他节次；长按未选项后拖动补选，普通滑动滚动正文，已选项使用点击取消。含第 13 节及以后的旧安排仅可原样保留；部分取消后若仍含更晚节次，会提示重新选择第 1–12 节并禁用保存。上述调整与 GitHub 入口当时一并替换同一 v0.5.6 Release 附件；历史同版本安装说明见 [发布核验](docs/testing/v0.5.6第二次修订发布验证.md)，功能验证见[课程周次验证](docs/testing/课程原有周次与拖动选择验证.md)及[滚动与晚节次修复验证](docs/testing/课程滚动手势与晚节次校验修复验证.md)。

### 登录校园网

1. 在“我的 → 校园网”的账号管理区域添加账号密码；首个账号自动设为默认，之后可在账号卡片中点击“设为默认”切换。
2. 连接校园公共 WiFi 或宿舍 WiFi，打开 App 即可尝试自动登录；也可在“校园网”页面顶部手动登录。
3. 认证开始后可以切换应用或锁屏，本次短时任务会继续；手动取消、划掉 App 或 WiFi 切换时停止。

姓名补全优先使用本机相同学号的已验证课表姓名。v0.5.7 中，仍未取得姓名且没有自定义备注的账号，在每次版本升级（versionCode 递增）后重新获得一次联网查询机会，包括旧版本已尝试但未取得姓名的账号。已有姓名和自定义备注保留，不切换默认账号或课表绑定。

联网查名必须等 App 在前台确认当前实体 WiFi 校园认证成功；普通可上网 WiFi、其他网络的成功、认证失败或超时均不能提前消费机会。查名前先加密保存本版本已尝试标记；之后成功、失败、验证码要求或 30 秒超时均不自动重查，同版本重启、覆盖安装及后续认证也不恢复机会。姓名未取得时账号仍可使用，之后导入课表仍可补全。详见 [姓名补全验证](docs/testing/账号姓名补全验证.md)。

确认无实体 WiFi 时，课表左上角显示“未连接WiFi”约 1 秒后恢复周次，不启动认证。认证开始后显示“正在登录校园网”，超过 3.5 秒仍未完成时显示“登录超时”约 1 秒后恢复周次，认证继续执行。确认成功立即替换为“校园网已连接”约 2 秒，并取消后续超时提示。实际进度和错误在“我的 → 校园网”查看；已联网不会自动退出，修改默认账号用于后续登录。

任一端点确认已认证后立即完成检查并取消另一端探测，避免因另一端 5 秒超时而延后成功提示；当前宿舍只需单次认证，已移除旧接口的二次认证。尚未确认在线时仍先识别正确网络，再提交选定账号。已合入 v0.5.3，见 [宿舍认证与快速确认验证](docs/testing/宿舍认证与快速确认验证.md)。

v0.5.4 进一步修复了请求取消清理较慢时仍先显示“登录超时”的问题：确认在线后立即显示成功，清理结束前保持原任务，避免重复登录。见 [认证成功与请求清理分离验证](docs/testing/认证成功与请求清理分离验证.md)和 [v0.5.4 验证记录](docs/testing/v0.5.4验证.md)。

### 查询资费与在线设备

进入“资费”，使用所选校园网账号登录学校自助服务。首次进入可自动查询，也可点击“登录查询”或“刷新资费”；学校要求验证码时自行填写。自动查询登录未完成时，可选择内置网页登录，预填密码但由用户点击登录。

后续源码在未确认 WiFi 连接时禁用“登录查询／刷新资费”和验证码提交，仍可查看上次资费和管理账号。此项尚未进入公开 APK，详见[资费刷新 WiFi 门槛验证](docs/testing/资费刷新WiFi门槛验证.md)。

四张卡片及设备信息均来自学校返回数据，缺失显示“—”或“未获取”。设备显示登录时间、在线时长和使用流量。注销前需选定一台设备并确认；注销本机会中断联网，可在校园网页面手动恢复。

### 更新与个性化

“我的 → 检查更新”直接检查新版：有新版弹窗，最新时提示“已是最新，无需更新”。弹窗按钮为“取消更新／忽略本次更新／立即更新”。下载需要用户操作，移动数据下载还需本次同意；后台下载遇到断网或换网后暂停，返回手动继续。安装由系统确认。

从 v0.4.8 及以前升级的迁移说明见“下载与安装”。“我的 → 个性化”提供三种背景：

- 颜色背景：蓝青、薄荷、薰衣草、樱粉、暖杏、灰白，以同色系的淡雅纸色作底，点击色卡选择。
- 跟随壁纸颜色：根据手机桌面壁纸主色生成柔和背景，随壁纸变化更新；不读取或展示系统壁纸原图。
- 自选壁纸：使用系统照片选择器导入图片，模糊强度可调 0–24，新图默认为 12；升级后原有图片保持清晰。

所有模式均有预览。切换模式或恢复默认会保留已选图片与模糊值；背景不改变按钮、导航及课程配色。外观配置仅在本机保存，不申请整个相册或广泛存储权限。部分动态壁纸暂未提供颜色时，保留本次已有颜色或使用蓝青背景。

## 网络与本机资料

| 功能 | 网络规则 |
| --- | --- |
| 校园网认证、资费查询 | 只使用当前实体 WiFi，不转用移动数据 |
| 学校课表 | 优先可上网的 WiFi，也可使用移动数据；换网后暂停 |
| 考试与成绩 | 优先可上网的实体 WiFi，也可使用移动数据；换网或后台后停止会话，手动重新登录 |
| 更新检查 | 可用 WiFi 或移动数据 |
| APK 下载 | 移动数据需单次同意，换网后暂停并手动继续 |

校园网账号、课表和教务资料分别使用 Android Keystore／AES-GCM 加密保存在本机，不做云端同步，排除系统备份。学校网页登录的 Cookie、验证码和密码仅在临时会话中使用。卸载或清除应用数据会删除本机资料；文件损坏时明确提示，不静默覆盖。

校园认证协议包含 HTTP 请求，本机加密不代表认证传输已加密。学校课表、资费和教务查询通过 HTTPS 访问，保留证书校验。当前不提供后台常驻、定时保活、IPv6 认证、自动连接 WiFi、本科课表、考试通知或成绩均分／绩点计算。

## 常见问题

- **课表导入暂停了？** v0.5.1 支持切后台继续导入；换网、断网、主动暂停或任务被系统停止后，需要返回前台手动继续并重新完成学校登录。已有完整课表仍可离线查看。
- **提示超时，但稍后能够上网？** 课表标题只是短暂提示，认证任务仍可能执行；到校园网页面查看实际结果。
- **资费页面需要额外登录？** 校园网接入和资费网站是两个独立会话。按提示填写验证码或使用内置网页登录。
- **改名后无法检查更新？** v0.4.8 及以前的旧地址被校验拦截，手动覆盖安装 v0.4.9 一次即可；之后可在 App 内检查更新。

反馈问题可提交 [Issue](https://github.com/TBeiMu/BJUT_gxz/issues)，说明版本、手机型号、Android 版本、网络类型及脱敏截图；请勿提交密码、Cookie、访问令牌或原始登录态页面。
